# 教师带课模式 · 字符串工坊

2026-11-12。当前范围为字符串课六个主线任务，由教师逐站发布；尚未经过学生课堂试教。代码和主线任务定义以 `lesson-curriculum.js`、`string-missions.js` 为准。

| 主线顺序 | 关卡 | 对应课堂内容 |
|---|---|---|
| 1 | 34 封签运送 | 首末索引，一个完整任务 |
| 2 | 39 断桥上的三块符石 | 切片取一段，桥板逐块升起 |
| 3 | 40 石像的回声鼓 | 拼接、重复、倒序，按拍亮灯后石像让路 |
| 4 | 41 矿井里的求救信号 | 包含、查找、统计，吊索救援后重新观察 |
| 5 | 42 被污染的净水池 | 去空格、替换、大小写，净水后通行 |
| 6 | 43 营地补给车 | 拆分与转换，装货、移动、卸货 |

教师在独立“发布任务”区域选择关卡、接收范围和补充说明后发送。接收范围可选全班（含稍后进入的学生）或指定学号，不依赖进度表选择和学生位置。集合、暂停、允许练习独立控制；学生确认任务后再从小屋出发。主线没有“必须写某个语句”的验收门槛。36保留为索引辅助任务；35、37、38不再出现在主线安排按钮中。六站任务使用不同玩法与布局，随机信息在每次运行生成，回放不重新抽取。

当前任务完成数和未获二三级帮助的完成数分别展示；无辅助完成仍不等于已掌握整个字符串课。格式化输出及课件剩余小方法需在PyCharm/课堂练习系统验收。

详细180分钟安排见 [字符串关卡与课堂衔接](STRING-LESSON.md)，与课程资料仓库中的S07方案同步。

## 入口和课堂控制

- 学生登录后进入 `/teaching/room` 小屋。任务板、地图桌、学习记录都从屋内打开浮层，关闭后留在小屋。未开课或下课后从地图桌选择自由练习；上课时任务板承载老师安排，地图暂停开放。`/teaching/free?embed=1` 是同源内嵌地图，上课期间访问旧地图或不属于当前任务的关卡链接都会回小屋。
- 教师从 `/teaching/teacher/login` 登录，进入 `/teaching/teacher/lesson`。原关卡发布管理仍在 `/teaching/teacher`。
- “开始新课堂”建立独立课堂编号，初始为呈现任务、在小屋集合的暂停状态。呈现、短讲、总结默认暂停；动手练习或“继续练习”恢复游戏。教师决定切换，系统不按时间或通关率自动推进。
- 多设备可查看。只有持有控制权的教师会话能下发课堂命令；其他设备明确“接管课堂”后，旧设备立即成为查看端。关闭页面不改变课堂状态。
- “原地暂停”保留关卡现场；“集合回小屋”暂停并让 DeepSeek 邀请学生保存代码后回小屋。“允许练习／继续”解除集合，学生从小屋门口出发；发送任务本身不解除暂停。
- 暂停冻结游戏播放时间，阻止运行、提交和场景继续；代码仍可编辑、保存。客户端每秒同步课堂状态，正常连接约一个轮询周期内生效；断线时已接入课堂的游戏暂停，恢复连接后同步服务器状态。
- 这是单服务进程、单班级课堂，不是多副本协调系统。沿用现有部署模式，不要多个进程同时写同一状态目录。

## 原45分钟索引试点参考（仅第一站）

| 时间参考 | 教师动作 | 学生动作 |
|---|---|---|
| 0—4分钟 | 开课，在小屋说明任务；发布任务让学生进入现场，再原地暂停讲解 | 从小屋出发，认出密封货箱、守卫要求与放行后的终点 |
| 4—9分钟 | “短讲示范”：演示 readTag 返回字符串，再示范 label[0] | 对照封签中的字符位置；游戏不会在讲解时继续计时 |
| 9—21分钟 | “动手练习”，巡视看分布 | 逐步完成同一送件关卡：拆封、区域岗、尾号岗、送达 |
| 21—26分钟 | 根据共同错误决定是否暂停纠偏 | 对照错误改代码；无需共同纠错时可缩短此段 |
| 26—39分钟 | 给卡住的单人或一组下发提示；必要时安排补救或复验 | 教师按需安排辅助练习或独立复验；其余学生完成本关并解释程序 |
| 39—45分钟 | “总结迁移”，检查本组结果后结束课堂 | 在PyCharm完成封签输入、首尾字符输出，向既有课堂练习系统交.py和两组运行结果 |

时间是参考。约八成独立完成是教师判断依据，不是自动切课门槛。大多数尚未掌握时先处理共同错误，缩减后续内容；少数学生可先跟进并保留“待补验收”。完整字符串课现可按上表继续，由教师明确安排下一站。

## 字符串索引：一个完整关卡（2026-11-12 修订）

索引部分主线只有“封签运送：通过两个核验口”（local-python-34），不再把首字、末位分成连续小关，也不再用同一份代码重复验证第二批作为“下一关”。

学生在同一场景、同一份程序里完成：走到货箱下方 → 拆封 → 读取完整字符串 → 到区域岗报首字 → 转入另一条仓道 → 到尾号岗报末位 → 送到法阵。两岗都通过才结算；可以先完成前半段，再逐步补全程序。有效算法均可使用，不检查是否出现指定索引语句。

`hero.openTag("货箱封签")` 是近距离动作，必须站在箱子正下方紧邻的一格，人物转向箱子，开盖、拆开封条、展开纸签约1.2秒后才执行下一行。`readTag("货箱封签")` 是拆封后的读取，返回本次货箱的完整字符串；未拆封不能隔空读出。随机内容每次运行可能变化，回放使用同一次模拟中记录的数据。地图点击只查看命令，不自动拆封或修改代码。

按需变式保留为教师工具，不自动排入学生主线：35为北侧仓道独立巩固（路线方向不同），36为显示字符位置的辅助练习，37为换取件位置的独立复验，38为索引复习。它们都包含两个核验口，教师按学生表现明确安排，通关不会自动推进到相似任务。主任务完成与独立复验通过在教师端分别显示，不把跟练完成冒充独立掌握。

课堂任务仍与自由练习记录隔离。原生返回统一回小屋；保存失败不阻断。主关完成后回小屋查看结果，等老师安排或结束课堂。

## 教师提示与掌握证据

教师可对单人、多选学生或全班发送：

1. 指明现场：高亮货箱封签，指出要观察的内容。
2. 指明操作：高亮代码区及相关行，说明取值位置。
3. 给关键代码：展示可参考的关键行，不代写、不代运行。

可自定义文字和代码。默认按每名学生当前任务选提示；自定义关键代码会计为辅助，无论选中的提示级别。提示用浮层展示，确认后收起，运行时不反复弹出，可重看。教师端分别显示待送达、已送达、已查看；查看不代表理解。

为了避免未确认提示时提前提交造成误记，2/3级提示在教师发出时即保守标记辅助，包含关键代码的自定义提示同样处理。该任务不能作为独立掌握证据；后续复验不继承上一题的辅助标记。教师可安排学生先继续，并保留待补验收。已经取得的独立验收证据不会因事后重复保存而降级。

教师视图只报告实际进度、辅助情况、已保存代码和客户端/服务器报告的具体错误，不自动推测学生的概念误解。最后的PyCharm迁移任务交到原有课堂练习系统，不在本游戏里假装已经自动验收。

## 远程教师登录与部署

在原服务的仓库目录、同一状态目录配置教师账号：

```sh
node teaching/tools/setup-teacher.cjs
```

按提示输入账号和至少10位密码；密码输入不显示，仅保存加盐scrypt散列。重置密码会使旧教师会话失效。不要使用隔离预览里的演示密码作为正式密码。配置后原教师管理路由也必须登录，不再凭本机地址取得教师权限；未配置时仅保留原本机旧管理入口，新的课堂控制必须先配置账号。

构建后，在原服务维护时段重启。保留原 `TEACHING_STATE_DIR`，不要复制测试目录覆盖它。采用原有进程管理方式；以下仅为启动参数示例：

```sh
npm run webpack
COCO_BIND_HOST=0.0.0.0 COCO_PORT=7778 node index.js
```

Windows PowerShell：

```powershell
npm run webpack
$env:COCO_BIND_HOST="0.0.0.0"
$env:COCO_PORT="7778"
node index.js
```

其他电脑在可达网络内访问 `http://服务器局域网IP:7778/teaching/teacher/login`，学生访问同一服务器的 `/teaching`。`0.0.0.0` 是监听参数，不能作为发给学生的地址。服务器防火墙需要允许该端口。本轮支持已有可达局域网，不包含公网域名、TLS或跨网穿透部署。

首次安装仍按原README准备依赖和aether运行器。本次开发验收通过 `COCO_PUBLIC_DIR` 把构建输出放到临时目录；正式部署无需此变量。

## 持久化与边界

全部文件位于现有 `TEACHING_STATE_DIR`：

- `teacher-auth.json`、`teacher-sessions/`：散列凭据和有期限的教师会话。
- `lesson-room.json`：当前课堂、控制权、学生分流、提示送达/查看记录和独立验收结果。
- `lesson-progress/<课堂ID>/`：本次课堂原生场景、代码和通过记录。
- `lesson-review/<课堂ID>/`：结束后复习用的独立运行记录，不覆盖课堂验收。
- `lesson-archive/`：开始下一堂课前归档上一堂课堂状态。

使用临时文件加原子重命名保存，服务重启后读取恢复；原学生账号与自由练习 `progress/` 不迁移、不删除。课堂过程与自由练习成绩不互相充当独立掌握证据。当前学生端复习入口展示最近一堂课的已完成任务；更早课堂的记录保留在归档目录，本轮不含历史课堂浏览器。

## DeepSeek 的温馨小屋（2026-11-12）

学生 `/teaching/room` 已成为像素风等候小屋。背景与人物由本地 Canvas 像素绘制，源代码在 `lesson-cabin.js`，样式在 `lesson-cabin.css`，没有新增外部图片或游戏引擎下载。两项新增静态文件合计约22KB（未压缩）。人物从门口归来、在屋里散步、眨眼和招手；炉火、热茶、窗外景物、钟摆与光尘持续变化。壁炉和书桌可点击互动，任务板打开当前任务浮层，地图桌打开世界地图浮层，书桌打开学习记录，门口根据真实课堂状态开闭。动画可手动暂停，也尊重系统减少动态效果设置，隐藏标签页停止绘制。

教师操作：

- **集合回小屋**：服务端暂停并阻止重新进入关卡，原关卡中出现 DeepSeek 集合对白。学生点击回小屋即可返回。先尝试本机备份，再尝试服务器保存，最多等2秒；保存失败、会话过期或超时都不阻止返回。本机草稿可在小屋查看，重新进入对应关卡后手动恢复，不自动覆盖或运行。
- **原地暂停 · 看讲解**：仍可在关卡里看现场、编辑和保存，不要求回小屋。
- **发布任务／继续练习**：小屋门打开，任务板显示当前任务。学生主动点击门口或出发按钮，DeepSeek 走向门口，随后进入对应关卡。
- **安排新任务**：原关卡提示先保存回小屋；小屋展示新任务，并通过已有任务分流接口进入正确关卡。
- **结束课堂**：显示归家提示，复习入口和记录保留。

验证：全量272项回归测试通过；浏览器实测小屋动画、集合时阻止重入但允许保存、未运行草稿保存归来、改派任务后的门口路由、断网保存保护（后续已改为允许回小屋），以及390px布局和减少动态效果。预览仍在隔离7791端口，未替换7778正式服务。

## 密封货箱：由变化的数据引出索引（2026-11-12）

索引试点五类任务统一改为运行时生成封签。地图初始只写“待拆封”，场景名只写第几批，点击帮助不展示答案。调用 `readTag("货箱封签")` 后，货箱显示已拆封与纸签，画面显示这次读到的字符串；补救关在读取后才显示字符位置。每次模拟由引擎生成新随机种子，同一次模拟内重复读取不变，回放使用已记录的数据，不在渲染时重新随机。

基础、独立、复验、挑战仍需用同一份程序完成两批货箱。两批首字候选互不重叠，末位数字候选也互不重叠；同时随机物品名和编号。`say("东")` 有可能碰巧通过第一批，但无法完成两批的整项验收。错报一次后守卫退回本批货箱并明确指出要读取再取值；同次运行继续枚举口令不能开门。有效的其他算法同样接受，不要求源码里必须出现 `label[0]`，也不要求变量一定叫 label。

PyCharm迁移练习中的固定示例仍作为测试样例保留，不是游戏本次货箱内容。参考程序先读取返回值，再取首字/末位或按顺序发言。全部275项测试通过；原生浏览器另外验证相同代码连续运行使用不同随机种子，以及写死“东”在第二批被拒绝。

## 保存失败不阻断回小屋（2026-11-12 修订）

原问题由两条客户端路径造成：课堂返回按钮等待保存成功才跳转；原生自动保存和通关弹窗仍要求复制代码后另开地图。现在它们统一使用 `teachingReturnToCabin` 返回动作：先在当前浏览器按学号、关卡保存草稿，尝试服务器保存（最多2秒），无论404、断网、超时或本机存储被禁用都继续返回。服务器成功才清除对应备份；失败后在小屋列出本地代码，进入同一关卡可主动恢复。恢复只更改编辑器，不运行程序或标记通关。本机备份不等于服务器已验收，也不能跨电脑同步。

通关弹窗保存尚未完成时也有独立的“回小屋”按钮；失败后主按钮改为“回小屋”。本机存储不可用时照样允许离开，但明确提示未能保留草稿，不虚报保存成功。既有无课堂返回入口的自由练习恢复逻辑保持原状。

验证：新增复现最初在404和网络失败时均不跳转的红测试，修复后20项针对性测试通过；涵盖两秒超时、浏览器存储禁用、学生草稿隔离、旧自动保存提示和通关弹窗。原生浏览器实测通关404后回小屋、草稿恢复、网络失败返回，全程无页面异常。未改服务器验收成功条件。


## 小屋统一入口与动线（2026-11-12）

- 登录 → 小屋；地图不是登录后的首页。
- 自由练习：地图桌 → 点地图节点查看详情 → 选择这关 → 任务板确认要求 → 出发。地图只选择目的地，不直接导航游戏；仍使用教师隐藏、开放和前置完成规则。
- 课堂练习：老师发布 → 小屋任务板 → 确认出发 → 同一任务内的多个场景连续完成 → 整项任务完成回小屋 → 查看结果、确认下一项。回小屋本身不改变学生当前任务，点击确认后才调用分流接口。
- 教师集合：返回小屋，地图和任务出发关闭；可查看课堂安排、提示和本机草稿。暂停与集合继续沿用不同语义。
- 学习记录：显示最近课堂实际完成结果、辅助/独立情况、已完成任务的复习入口、教师提示与本机恢复草稿。自由练习各关进度显示在地图及选中的任务卡，不混充课堂掌握证据。
- 游戏中的返回和整关通关继续都回小屋；同任务的下一场景仍直接继续。保存失败返回与草稿恢复逻辑保留。
