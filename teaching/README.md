## 25软件1班学号入口

学生打开 `/teaching`，输入自己的学号，点击「进入课堂」。首次登录自动建立学习记录，以后登录同一学号继续原来的进度；不再有单独的创建账号步骤。用户名就是学号，不设密码。学号限定为4—20位数字，前导零会保留。登录后显示当前学号和四小节关卡入口；点击「退出登录」会结束当前会话。代码及关卡完成状态按学号分别保存，换一台电脑登录同一学号仍可读取本服务中的进度。

**学号免密只是在选择进度档案，不能核验身份。**知道他人学号的人也能进入其档案并改写进度；目前也没有导入班级学号名册，任何符合格式的学号都能自动建立学习记录。因此此入口只供本机演示，不能作为正式成绩或面向机房开放的登录方案。正式使用前至少需要确定学生名册、身份核验和教师恢复/管理流程，并完成HTTPS与多人访问验证。

账号、进度、登录会话分别保存在Git忽略的 `state/students/`、`state/progress/`、`state/student-sessions/`。会话Cookie设为HttpOnly、SameSite=Lax，12小时失效；表单带校验值，退出会使当前会话失效。旧匿名Cookie对应的进度文件保留在 `state/`，不会自动并入某个学号。

## 本机教师端：进度与发布

在**运行服务的这台电脑**打开 http://127.0.0.1:7778/teaching/teacher 。教师页列出已有学习记录的学号、各关「未开始 / 已进入 / 进行中 / 已完成」状态和最后保存时间；点击学号可看各关已保存代码。状态来自本地关卡会话，不是现有课堂练习系统的成绩。

每关有「隐藏/显示」与「开放/关闭」控制，对整个25软件1班生效。隐藏：学生页不出现卡片，不计入总数，不出现空分组，直接访问地址或API也不能进入；显示但未开放：学生看到「等待老师开放」；开放：学生可以进入。隐藏会同时关闭关卡，重新显示只恢复锁定卡片，需要再点「开放此关」才能进入。隐藏、关闭均不删除已保存代码和完成记录。

正常教学关默认显示，只有第一关默认开放；`prototype`测试关默认隐藏。当前22—25四个样关已隐藏。教师页仍显示所有关卡，并提供「跳到互动样关」入口。本机课堂首页增加「教师管理」链接；远程学生页不显示该入口，教师接口继续限制本机来源。显示与开放状态分别保存到Git忽略的 `state/classroom.json` 的 `visibility` 与 `releases`，按原子写入持久化，重启保留。下一关衔接会跳过隐藏关卡，不向学生暴露隐藏关卡名称。

数据持久化采用JSON文件，当前未使用SQLite。默认目录为本项目的 `teaching/state/`，可用 `TEACHING_STATE_DIR` 指定其它固定目录；重启时必须继续使用同一目录。账号、已保存代码、逐场景通关记录和开放开关均从磁盘读取，普通服务重启不会清空它们。进度与开放状态通过临时文件加原子重命名更新，接口写入成功后才响应；浏览器尚未提交到服务的编辑不在此保证内。登录会话12小时到期后重新输入学号，学习记录仍保留。

## 学生怎么做

1. 打开本地入口；输入自己的学号，点击“进入课堂”；首次自动建立学习记录。从首页选择关卡，点击“开始”，确认Python。
2. 看清目标，在编辑区写 `hero.moveUp()` 等命令，点击“运行”。本关可用命令列在编辑器下方。
   需要让英雄说出信息时，可以写 `print("你好")` 或 `hero.say("你好")`；两种写法在**原创关卡**里效果相同。连续写多条会依次发言，气泡列位于英雄头顶上方、人物中线右侧；每条气泡的底边偏左有同样的短尖角，外框与尖角连成一体并指向英雄；较新的气泡把旧气泡向上推，屏幕最多显示最近四条。回放进行时每条约保留 5 秒，进入和退出时会短暂淡入淡出，播放结束后也会继续淡出。`print("第", 2)` 这类多个位置参数会用空格连接。这里的 `print` 是游戏内的发言适配；在 PyCharm 中它仍向运行窗口输出。
3. 左侧所有目标成功才算完成。失败时先看是哪条目标未完成，再改对应命令。
4. 修改后停留几秒，代码会按学号保存到本服务。“运行”用于调试；确认成功后点击“提交”，完成实时演示并记录完成状态，验收通过后点击“下一场景”或“下一关”继续；下一关未开放时等待老师发布。通关截图和TXT仍交现有课堂练习系统。
5. 不需要在本地入口注册官方账号；不要点击商城等无关功能。代码中的hero由游戏提供，不能直接复制进普通PyCharm运行。

本地关卡已隐藏官方注册和AI入口；胜利弹窗显示本地保存说明，并衔接下一场景或下一关；仍可主动返回选关。其他官方菜单仍保留；当前学号入口不是课堂成绩系统。

## 哪些文件由我们控制

- `levels/local-python-01.json` 等：运行时读取的关卡，包含地图实体位置、目标、题面、系统参数。修改后刷新关卡即可，不用改官方数据库。
- `map-designs.js`：6关的地图源数据；修改走廊、检查点、出口、宝石、尖刺和巡逻参数。`tools/build-levels.js`把它们生成为原生关卡，再运行 `node teaching/tools/build-levels.js`。注意重新生成会覆盖手工编辑的关卡JSON。
- `rules-system.js`：原创碰墙、检查点顺序、出口、尖刺和巡逻规则；通过原生System接口执行。
- `print-to-say.js`、`speech-stack.js`：仅在原创关卡把 Python `print` 连接到英雄发言，并控制气泡数量与显示时长。
- `local-levels.js`、`student-accounts.js`、`account-page.js`、`classroom.css`、`classroom-state.js`、`teacher-page.js`：本地关卡、学号入口、教师进度与发布API。只处理本项目的ID前缀，其他请求仍按原开发代理工作。
- `state/`：按学号保存账号与代码进度、按随机会话令牌保存登录状态，已Git忽略。
- `checks/`：实际浏览器截图。
- `common/`：通用素材/组件引用与接口采样，授权说明见其README。

客户端适配仅作用于`local-python-NN`关卡：固定关卡配置的英雄/能力，绑定本地会话的编辑者，跳过向官方CodeLog发送本地关卡代码。没有修改官网关卡访问权限或付费检查。
